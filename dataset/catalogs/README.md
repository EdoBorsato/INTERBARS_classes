the scripts named below (no hand edits: change the script or its inputs). Plan and defect list:
`docs/SPECZ_SEARCH_PLAN.md`.

## Spec-z search (`scripts/search_specz.py`, 2026-09-28)

Centres: main galaxy (`tid` = system) and named companion (`system_comp`), `specz_search_centres.csv`
(43). Every service queried at 10′ (`--r-env 600`): VizieR 2dFGRS, 6dFGS, 2MRS, GAMA DR4, LAMOST DR5;
Data Lab SDSS DR17 `specobj`, DESI DR1 `zpix`; NED objdir; SIMBAD basic. Raw pools in `specz_search/raw_<svc>.csv`
(`--refresh` re-queries). Quality: SDSS zwarning = 0; DESI zwarn = 0 & Δχ² > 25; 2dF/6dF/GAMA Q ≥ 3;
LAMOST class GALAXY/QSO; NED spectroscopic flag; SIMBAD quality A–C.

| file | content |
|---|---|
| `specz_matches.csv` | every match within 10″…10′ of a centre: `tid`, `system`, `role`, `survey`, `obj_id`, `ra`, `dec`, `z`, `zerr`, `zqual`, `good`, `zkind` (spec/phot/lit), `is_star`, `usable`, `sep_arcsec`, `dv_kms` (vs the system's hand z), `extra` (SDSS plate/mjd/fiber; DESI survey/program/healpix) |
| `interbars_specz.csv` | one row per system: `z_main` = nearest usable spec-z within 5″ (`z_main_survey`, `n_main_meas`, `main_all_z`), companion `z_comp`, `dv_comp_kms`, `comp_sep_arcsec/kpc`, environment `n_neighbours` (|Δv| < 1000 km/s within 10′, main/companion excluded), `n_neighbours_100kpc`, nearest neighbour, `flags`: `hand_mismatch` (IC 775: hand 0.0203 has no survey counterpart, all four surveys give 0.0258; LEDA 1232789: .dat value wrong), `ambiguous_main` (NGC 2864: a NED value 0.011 at the centre), `comp_unbound` (LEDA 1436844's companion is background) |
| `interbars_neighbours.csv` | one row per (system, galaxy) within the window, measurements of one galaxy merged (< 3″, |dz| < 0.002) |

Check page: `output/specz_gallery/index.html` (`scripts/specz_gallery.py`): LS DR10 150″ zoom with numbered

## DESI spectra and FastSpecFit

`dataset/spectra/` (README there) holds the archived 1D spectra. The DESI healpix coadd + redrock files,
SFD dust maps, stellar templates and Tractor bricks that FastSpecFit needs live under `output/desi_redux/`
(gitignored, ~2.5 GB; `scripts/fastspecfit_env.sh`, `scripts/fetch_desi_tractor.py`). Line measurements:
`scripts/run_fastspecfit.py` → `results/tables/fastspecfit_bpt.csv`; student notebook
`notebooks/bpt_fastspecfit.ipynb`.

## SDSS spectra through FastSpecFit (`scripts/sdss_to_desi.py`, 2026-09-28)

The 40 SDSS DR17 spectra of the sample (27 mains, 13 companions; two pair members share a fibre) are
wrapped into DESI-format coadd + redrock files under `output/desi_redux/iron/healpix/sdss/dr17/<plate>/`
(one fake healpix per plate, `TARGETID` = plate·mjd·fiber digits): flux-conserving resampling of the
SDSS log grid onto DESI's 0.8 Å linear grid (FastSpecFit's output grid assumes constant dispersion),
three arm blocks at the DESI camera boundaries, the SDSS `wdisp` turned into an 11-diagonal
resolution matrix, the pipeline z / zwarning / class as the "redrock" redshift, and no Legacy Survey
ids so that FastSpecFit matches the DR9 Tractor photometry by position (bricks fetched to `$FPHOTO_DIR`).
`output/desi_redux/sdss_wrapped.csv` lists them; `scripts/run_fastspecfit.py` fits them with labels
`*_sdss`; `scripts/compare_sdss_spzline.py` compares the fluxes with the SDSS pipeline's `SPZLINE`
fits and, for galaxies with both spectra, with the DESI measurement
(`results/tables/sdss_line_comparison.csv`, `results/figures/sdss_line_comparison.png`).

## pPXF line measurements, both surveys natively (`scripts/run_ppxf.py`, 2026-09-28) — the adopted method

The DESI-format wrapper above is superseded. `run_ppxf.py` fits every DESI coadd row and SDSS lite file
of the sample with pPXF 9.5 (E-MILES SSPs + Gaussian gas templates at each spectrum's own resolution;
three kinematic components: stars, narrow Balmer, narrow forbidden; multiplicative polynomial; pixels
with ivar = 0 excluded — the SDSS `and_mask` is *not* used, it flags most of the red half on old plates).
52 spectra in 2.3 min → `results/tables/ppxf_lines.csv` (fluxes in 1e-17 erg/s/cm², formal errors, BPT
ratios and class, σ⋆, light-weighted age / metallicity; FastSpecFit values merged where they exist),
`output/ppxf/<label>.png`. `scripts/compare_line_fitters.py` → `results/tables/line_fitter_comparison.csv`,
`results/figures/line_fitter_comparison.png`: pPXF / FastSpecFit 0.89–0.95 (DESI) and 1.00–1.07 (SDSS)
per line with 0.02–0.04 dex scatter; pPXF / SDSS pipeline 1.00–1.02 for [O III], Hα, [N II] (0.01 dex) and
1.16 for Hβ (the pipeline under-corrects the Balmer absorption); DESI 1.5″ vs SDSS 3″ fibres of the same
galaxy give the same class for 7/8 (IC 3147B sits on the Kauffmann line). Note: with E-MILES (FWHM 2.5 Å)
the DESI σ⋆ is not meaningful (DESI resolves better than the templates); line fluxes are unaffected.
