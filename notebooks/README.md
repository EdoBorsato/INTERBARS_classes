# notebooks/ — nuclear spectroscopy of the interbars sample (student series)

Run in the `fastspecfit` conda env: `source scripts/fastspecfit_env.sh && jupyter lab notebooks/`.
Each student sets `MY_SYSTEMS` once, in section 1.2 of notebook 1; it is saved to `my_systems.json` and
read by notebooks 2 and 3, so the same galaxy / pair runs through the series. Every notebook works for
DESI-only, SDSS-only and mixed systems.
The notebooks are generated by `build_series.py` (edit the builder, not the .ipynb; `--execute`
re-runs them) so that text and code stay in one reviewable file.

| notebook | content |
|---|---|
| `01_data_and_spectra.ipynb` | the sample table; **choose `MY_SYSTEMS`**; querying SDSS DR17 / DESI DR1 for spectra around each of your galaxies; the Legacy Survey image with a hand-built WCS and every fibre of the system drawn on it (DESI 1.5″, SDSS 3″), kpc scale, fibre-to-total flux; the spectrum file (DESI coadd arms or SDSS lite table), pixel scale in Å and km/s, spectral resolution from the DESI `RESOLUTION` matrix and the SDSS `wdisp` (both surveys always shown, one from a reference spectrum if needed); two spectra of your system overlaid |
| `02_continuum_and_lines.ipynb` | **pPXF** as the engine, one step per section on its own objects: reading DESI / SDSS spectra with the project readers, air wavelengths and the log grid, E-MILES stellar + Gaussian gas templates and the three kinematic components, the fit, weights → fluxes in erg/s/cm², the Balmer-absorption effect, the broad-Hα trial and its four adoption tests, cross-checks against the pipeline function, FastSpecFit and the SDSS pipeline |
| `03_bpt_classification.ipynb` | **per student**: set `MY_SYSTEMS` to a galaxy / pair / few; its spectra (main, companion, DESI and SDSS) go on the [N II] BPT over the contours of SDSS spectroscopic pairs and Nair & Abraham barred galaxies with the rest of the sample in grey; a per-nucleus verdict (contour level in each population, pairs / barred density ratio, class); the galaxy's full table (fluxes, Balmer decrement and E(B−V), dust-corrected Hα, kinematics, age, broad-line test); the whole sample and the per-class statistics at the end for context |
| `appendix_line_fitting_by_hand.ipynb` | the same measurement of IC 3147B redone with numpy/scipy only (templates × σ⋆ × dust by NNLS, smooth correction, joint Gaussian fit); agrees with FastSpecFit and pPXF to ≤ 5 % per line |

Data needed: the DESI iron healpix coadds of the sample under `output/desi_redux/` (~4 GB; only the coadd of
each target's healpix is read), the SDSS lite files in `dataset/spectra/`, the E-MILES templates in
`output/ppxf/sps_models/` (13 MB), and for notebook 3 the cached comparison catalogues in `output/comparison/`
(150 MB). FastSpecFit and its 1 GB of inputs are only needed for the cross-check column. For web distribution:
one coadd row per target instead of the full healpix file (to do).

## Student bundle

`scripts/make_student_bundle.py` packs everything the notebooks need into `dist/interbars_students.zip`
(46 MB): the executed notebooks and their builder, the four scripts they import, the catalogues and tables,
the SDSS lite spectra, the DESI coadds **trimmed to the sample's rows** (1 MB each instead of 200–500 MB,
same HDU layout so the readers do not notice), the E-MILES templates and the two SDSS comparison
catalogues. The environment is pip-only (`requirements-students.txt`, or `environment-students.yml`
for conda): no DESI software. `scripts/test_student_bundle.sh` is the setup test: a fresh venv from the
requirements file, the zip unpacked in a temporary directory with the developer's environment variables
unset, the three notebooks executed there (passed 2026-09-28: 11 + 24 + 14 s, 683 MB venv).

## Web-based, deployed (2026-09-28)

The bundle is published at **https://github.com/EdoBorsato/INTERBARS_classes** (public; pushed from this
machine with a write deploy key). Binder builds it from `requirements.txt` + `runtime.txt` (first build
2026-09-28 on the 2i2c federation member, image 845 MB, ~2 min; later launches from cache in ~1 min):

* Binder: https://mybinder.org/v2/gh/EdoBorsato/INTERBARS_classes/HEAD?urlpath=lab/tree/notebooks/01_data_and_spectra.ipynb
* Colab: https://colab.research.google.com/github/EdoBorsato/INTERBARS_classes/blob/HEAD/notebooks/01_data_and_spectra.ipynb
  (each notebook's first cell installs pPXF and clones the bundle)

To update the student repo after changing the notebooks: `python scripts/make_student_bundle.py --repo-url
https://github.com/EdoBorsato/INTERBARS_classes`, then in `dist/interbars_students`: `git init -b main`
(the build wipes the folder), commit, `git remote add origin git@github.com:EdoBorsato/INTERBARS_classes.git`,
`git push -f origin main`. Binder rebuilds on the next launch.
